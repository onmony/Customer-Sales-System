# Order V1

## Purpose

Define minimum order capability for Phase 1 customer-to-invoice workflow.

## Included Scope

- Create order for selected customer.
- Add products as order items.
- Resolve pricing for order items.
- Save order with immutable pricing snapshots.
- Prepare order for invoice creation.

## Excluded Scope

- Warehouse allocation.
- Shipment planning.
- Delivery confirmation.
- Payment collection.
- Approval workflows.
- Returns.

## Business Rules

### ORD-1 Tenant Scope

Every order belongs to one tenant.

### ORD-2 Customer Required

An order must have a customer.

### ORD-3 Items Required

An order must have at least one order item before it can be saved.

### ORD-4 Product Required

Every order item must reference a product.

### ORD-5 Pricing Snapshot Required

Every saved order item must include an immutable pricing snapshot.

### ORD-6 Historical Safety

Saved order pricing must not change when customer pricing changes later.

## Acceptance Criteria

- A user can create an order from a customer.
- A user can add products to the order.
- Pricing resolves for each order item according to Pricing documentation.
- Saved order items preserve pricing snapshots.

## Open Questions

- Order statuses are not finalized.
- Saved order edit policy is not finalized.
- Order cancellation policy is not finalized.
- Draft order behavior is not finalized.
