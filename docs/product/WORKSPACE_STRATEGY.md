# Workspace Strategy

## Purpose

This document defines the workspace strategy for operational modules. This is NOT screen design. This documents the primary user, primary screen, primary responsibility, and the one action that should take less than one minute for each workspace.

Related documents:

- [Customer Workspace](business/CUSTOMER_WORKSPACE.md) - Customer Workspace as READ MODEL
- [Navigation](NAVIGATION.md) - Navigation hierarchy

## Customer Workspace

**Primary User:** Salesperson

**Primary Screen:** Customer Workspace (overview section)

**Primary Responsibility:** Assess customer situation and create accurate order

**One Action (< 1 Minute):** Create new order

**Context:** The salesperson opens a customer, immediately sees outstanding balance, credit status, last order, frequently ordered products, and current pricing. The salesperson can create an accurate order in under one minute.

## Warehouse Workspace

**Primary User:** Warehouse Manager

**Primary Screen:** Warehouse Request Queue

**Primary Responsibility:** Pick and pack orders for shipment

**One Action (< 1 Minute):** Mark warehouse request as picked

**Context:** The warehouse manager sees a queue of pending warehouse requests. The warehouse manager can quickly mark a request as picked when items are retrieved from inventory.

## Finance Workspace

**Primary User:** Finance Manager

**Primary Screen:** Invoice Queue

**Primary Responsibility:** Issue invoices and track payments

**One Action (< 1 Minute):** Issue invoice

**Context:** The finance manager sees a queue of generated invoices awaiting issuance. The finance manager can quickly issue an invoice when invoice number is assigned.

## Management Workspace

**Primary User:** Business Owner / Manager

**Primary Screen:** Dashboard

**Primary Responsibility:** Monitor business health and make decisions

**One Action (< 1 Minute):** View daily summary

**Context:** The manager sees a dashboard with daily orders, revenue, pending tasks, and alerts. The manager can quickly assess daily business health.
