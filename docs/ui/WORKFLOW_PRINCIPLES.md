# Workflow Principles

Workflows form the backbone of the ERP experience. Business processes are continuous journeys, not isolated data entry events. The system must reflect and support these natural flows.

## Guided Work Philosophy

The software should never leave users wondering: *"What should I do next?"*

Every workspace should naturally guide the user to the next logical business step in the process. Instead of presenting a dashboard of unrelated actions, the system should encourage the natural progression of work.

**Example Flow:**
Customer Created → Create Pricing → Create Order → Generate Invoice → Record Payment

## Core Principles

### Complete Workflows Instead of Isolated Screens
Design for the entire lifecycle of a task. A user should be able to initiate, process, and conclude a business activity within a unified flow, rather than jumping between disjointed modules.

### One Business Process From Start to Finish
A workflow represents a single, cohesive business objective (e.g., fulfilling an order). The system should maintain the context of this objective throughout all related steps.

### Users Should Rarely Leave a Workspace
A workspace should contain all the necessary tools, data, and context required to complete a specific workflow. Minimizing navigation away from the active workspace preserves focus.

### Workflows Guide Users Naturally
The system should proactively surface the next logical steps, making the "happy path" the most obvious and accessible choice.

### Minimize Unnecessary Confirmations
Do not interrupt the user's flow with redundant confirmation dialogs for routine, easily reversible actions. Reserve confirmations for critical, destructive, or highly consequential operations.

### Eliminate Duplicate Data Entry
Information entered once should seamlessly flow into subsequent steps of the workflow. Users should never be required to re-key data that the system already possesses.

### System Remembers Previous Decisions Where Appropriate
The software should learn from user behavior and remember context, applying sensible defaults based on recent actions or historical patterns to accelerate repetitive tasks.
