# Page Types

To maintain consistency, every screen in the application must conform to one of the following standard Page Types.

## Standard Page Types

### Dashboard
*   **Purpose:** Aggregated overview of metrics, key performance indicators, and prioritized tasks.
*   **Structure:** Widget-based layout. High level of data summarization. Used primarily as a landing page or for management overviews.

### List
*   **Purpose:** Viewing and managing collections of records (e.g., All Customers, Recent Orders).
*   **Structure:** Dominated by a highly functional data table. Includes robust filtering, sorting, and bulk action capabilities.

### Detail
*   **Purpose:** Viewing the complete, read-only record of a single entity.
*   **Structure:** Organized into logical sections or tabs. Emphasizes readability and clear presentation of status and relationships.

### Workspace
*   **Purpose:** An active environment for completing a specific business process (e.g., Creating an Order).
*   **Structure:** A hybrid layout combining forms, contextual data panels, and summary sections. Highly interactive and optimized for keyboard data entry.

### Settings
*   **Purpose:** Configuration of system or user preferences.
*   **Structure:** Standardized forms grouped logically, often using vertical tabs or a master-detail pattern.

### Lookup
*   **Purpose:** A specialized, simplified interface used specifically for finding and selecting a record to link to another (e.g., selecting a Product to add to an Order).
*   **Structure:** Often presented in a Modal or Drawer. Contains a search bar, filters, and a simplified list view.

### Report
*   **Purpose:** Deep analysis of data based on specific parameters.
*   **Structure:** Complex filtering options combined with charts, graphs, and highly dense data tables optimized for export.

### Wizard (Use Sparingly)
*   **Purpose:** A linear, multi-step process for rarely performed or highly complex tasks.
*   **Structure:** Sequential steps with strict validation before progression.
*   **Rule:** Only to be used if unavoidable. Professional users generally prefer a unified Workspace over a restrictive step-by-step Wizard for daily tasks.
