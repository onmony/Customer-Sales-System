# Typography System

Typography is the most critical visual element in a data-dense ERP application. It must be engineered for extreme legibility, rapid scanning, and high information density.

## Core Principles

### Font Family Philosophy
Select a highly legible, modern sans-serif typeface designed specifically for user interfaces and complex data tables. It must have easily distinguishable characters (e.g., differentiating '1', 'l', and 'I') and proportional tabular figures (monospaced numbers) to ensure columns of data align perfectly.

### Heading Hierarchy
*   **Philosophy:** Headings establish the structure of a workspace. The hierarchy must be shallow (rarely exceeding 3 levels) to avoid excessive vertical spacing.
*   **Usage:** Used to label workspaces, distinct sections within a form, or primary data blocks.

### Body Text Hierarchy
*   **Philosophy:** The workhorse of the application. The primary body size must strike the exact balance between legibility and density.
*   **Usage:** Standard data entry, descriptions, and read-only text.

### Table Typography
*   **Philosophy:** Tables require specialized typographic treatment.
*   **Rules:** Use tabular (monospaced) numerals for financial and numeric data to ensure decimal alignment. Font sizes in tables may be slightly smaller than standard body text to maximize row density, provided legibility is maintained.

### Form Typography
*   **Philosophy:** Input text must clearly contrast with labels and placeholder text.
*   **Rules:** Labels use a smaller, slightly heavier weight to stand out without competing with the data. Input text uses standard body size.

### Density and Readability
*   **Philosophy:** Maximize data per square inch without sacrificing clarity.
*   **Rules:** Rely on font weight (Regular vs. Medium/Semibold) and subtle color variations (Dark Gray vs. Black) rather than drastic size changes to establish hierarchy in dense layouts. Line heights must be tight but comfortable.
