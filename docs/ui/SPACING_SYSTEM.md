# Spacing System

Spacing organizes information and guides the user's eye. In an ERP, spacing must be tightly controlled to balance readability with the high information density required by professional users.

## Core Principles

### Dense but Readable
The interface must present a large amount of data simultaneously. Avoid the "consumer web" trend of excessive, airy padding. Use the minimum amount of spacing necessary to separate distinct visual elements clearly.

### Consistent Spacing
All margins and padding must adhere to a predictable, mathematically sound scale (e.g., based on a 4px or 8px grid). Arbitrary spacing values are prohibited.

### Vertical Rhythm
Maintain a consistent vertical flow down the page. Headings, form fields, and data tables should align to a predictable vertical grid to reduce cognitive friction as the user scans downward.

### Alignment
Strict alignment is mandatory. Form fields must align horizontally and vertically. Numbers in tables must right-align. Visual structure should be enforced through alignment rather than relying solely on lines or boxes.

### Grouping by Proximity
Use tighter spacing to group related items (e.g., a label and its input field) and looser spacing to separate distinct sections (e.g., Shipping Address vs. Billing Address). Proximity must be the primary tool for communicating relationships.
