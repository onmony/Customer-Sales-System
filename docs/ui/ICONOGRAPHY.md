# Iconography System

Icons are visual aids used to accelerate recognition. In a professional ERP, they are used strictly for utility, never for decoration.

## Core Principles

### Icons Support Text
Icons are most effective when paired with concise text labels. The combination of symbol and text ensures absolute clarity for all users, regardless of familiarity with the system.

### Icons Never Replace Text (Usually)
Avoid relying solely on icons for critical actions or complex concepts. Ambiguous icons cause hesitation and errors.
*   *Exception:* Universally recognized utility icons (e.g., a magnifying glass for search, an 'X' to close, or standard formatting icons) may be used without text to save space in tight toolbars, provided they include descriptive hover tooltips.

### Consistent Icon Usage
An icon must mean the exact same thing everywhere in the application. Do not use a floppy disk icon for "Save" on one screen and a checkmark icon for "Save" on another.

### Business-First Iconography
Choose icons that accurately reflect business concepts (e.g., distinct, professional icons for Invoices, Orders, Customers, Warehouse). Avoid overly playful, cartoonish, or ambiguous metaphors.
