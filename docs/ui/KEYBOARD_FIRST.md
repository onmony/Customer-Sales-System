# Keyboard First

For power users and data entry professionals, the keyboard is the fastest input device. The application must be fully navigable and operable without reliance on a mouse.

## Core Principles

### Keyboard is First-Class
Keyboard accessibility is not an afterthought or an accessibility compliance checkbox; it is a primary design requirement for productivity.

### Power Users Stay on Keyboard
A user should be able to complete entire workflows—from data entry to submission and navigation to the next task—without ever moving their hand to the mouse.

### Standard Shortcuts
Implement universally recognized keyboard shortcuts (e.g., Enter to submit, Escape to close/cancel, Tab for navigation, Ctrl/Cmd+S to save) to leverage existing user muscle memory.

### Predictable Focus Order
The `Tab` key must move focus through the interface in a strictly logical, predictable sequence that matches the visual flow of the workflow (typically left-to-right, top-to-bottom). Focus states must be highly visible.

### Minimal Mouse Dependency
Any action that can be performed with a mouse must have an equivalent, efficient keyboard alternative.

### Keyboard Shortcuts Consistent Across Workspaces
A shortcut that performs a specific action (e.g., "Create New") must perform that same action consistently across every module and workspace in the application.
